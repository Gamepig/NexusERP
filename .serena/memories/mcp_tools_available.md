# 可用的 MCP 工具清單

## 已驗證正常運作的 MCP 工具

### 瀏覽器自動化工具
1. **playwright-mcp** - Playwright 瀏覽器自動化 ✅
2. **puppeteer-mcp-server** - Puppeteer 瀏覽器自動化 ✅ (需設定)

### 任務管理工具
3. **task-master-ai** - AI 驅動的任務管理系統 ✅

### 程式碼分析工具  
4. **serena** - 程式碼分析、搜尋、編輯工具 ✅

### 時間工具
5. **time-mcp** - 時間相關操作工具 ✅

## 工具詳細資訊

### 瀏覽器自動化使用場景
- **UI 測試自動化**: 兩個工具都可以進行網頁 UI 測試
- **資料抓取**: 可以自動化網頁資料收集
- **頁面截圖**: 支援視覺化驗證
- **表單填寫**: 自動化表單輸入和提交
- **頁面互動**: 點擊、懸停、鍵盤輸入等

### 工具選擇建議
- **Playwright-mcp**: 推薦作為首選，無需額外設定
- **Puppeteer-mcp-server**: 適合需要 Puppeteer 特有功能的場景
- **Task-master-ai**: 適合大型專案的任務規劃和追蹤
- **Serena**: 適合程式碼分析和重構工作
