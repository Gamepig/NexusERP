# 工具優先順序和知識庫配置

## 主力知識庫

**Serena MCP 是主力知識庫**
- Serena MCP 是專案的主要知識管理系統
- 所有重要的專案知識、程式碼模式、問題解決方案都應優先記錄到 Serena MCP
- 當需要記錄專案相關的技術決策、實作細節、問題修復記錄時，應使用 Serena MCP 的記憶功能

## 工具使用優先順序

1. **Serena MCP** - 主力知識庫和專案記憶
2. **TaskMaster AI** - 任務管理和進度追蹤
3. **其他工具** - 支援性功能

## 記憶策略

- 專案開發過程中遇到的重要問題和解決方案 → Serena MCP
- 技術架構和實作決策 → Serena MCP  
- 資料庫結構和 API 設計 → Serena MCP
- 任務進度和計劃 → TaskMaster AI
- 程式碼品質和測試記錄 → Serena MCP
