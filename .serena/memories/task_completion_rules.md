# Task 完成驗證規則

## 🚨 **強制性規則：Playwright E2E 測試驗證**

### **規則內容**
任何涉及前端功能或 API 整合的任務，在標記為 "done" 之前，**必須**通過 Playwright E2E 測試進行完整的實際操作驗證。

### **適用範圍**
- 前端 UI 功能開發
- API 端點實作
- 用戶操作流程
- 資料庫操作整合
- 認證和授權功能

### **驗證要求**
1. **功能性測試**：所有 CRUD 操作必須通過瀏覽器實際操作測試
2. **整合測試**：前後端整合必須在真實環境中驗證
3. **用戶體驗測試**：確保用戶可以完成完整的操作流程
4. **錯誤處理測試**：驗證錯誤情況的正確處理

### **違反規則的後果**
- 任務不得標記為完成
- 必須補充 Playwright 測試驗證
- 重新評估任務完成度

### **最佳實踐**
- 使用現有的 Playwright 測試腳本
- 在 `documents/test_scripts/` 目錄中找到相關測試
- 執行測試並記錄結果
- 在任務更新中包含測試結果

### **測試執行指令範例**
```bash
# 供應商模組測試
cd documents/test_scripts
node playwright-suppliers-routes-test.cjs

# 完整系統測試
node playwright-comprehensive-test.cjs
```

### **記錄要求**
- 測試執行時間
- 測試結果截圖或日誌
- 發現的問題和修復記錄
- 最終驗證確認
