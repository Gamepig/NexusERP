```bash

# Go 服務測試
go test -v -cover ./...

# 前端功能測試
npm run test
```

##### **整合測試** (General Purpose Agent)
```bash
# 端到端測試
npx playwright test

# API 整合測試
newman run api-integration-tests.json

# 性能測試
artillery run performance-test.yml
```

##### **安全測試** (所有代理)
```bash
# SQL 注入測試
sqlmap -u "http://127.0.0.1:8000/api/*"

# XSS 掃描
xssstrike -u "http://127.0.0.1:8000"

# 多租戶隔離測試
python tenant-isolation-test.py
```
