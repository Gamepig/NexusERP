## 🛠️ 修復實施方案

### 1. Phase 1 修復：報價單號格式錯誤
**檔案**: `frontend/resources/views/quotes/show.blade.php:52`

**修復前**（錯誤計算邏輯）:
```php
QT-{{ str_pad($quote['id'] ?? 0, 3, '0', STR_PAD_LEFT) }}
// 結果：QT-019 (基於ID計算)
```

**修復後**（使用API數據）:
```php
{{ $quote['quote_number'] ?? 'QT-000' }}
// 結果：QT2025000011 (使用實際API返回值)
```

**修復邏輕**: 前端不再嘗試計算格式，直接使用後端API提供的正確格式化數據。

### 2. Phase 2a 修復：產品名稱顯示錯誤（臨時解決方案）
**檔案**: `frontend/app/Http/Controllers/Web/QuoteController.php:133-175`

**問題根因**: Go API 的 `/quotes/{id}` 端點在 JOIN 產品表時失敗，返回空的產品名稱。

**臨時修復邏輯**:
```php
private function normalizeQuoteData($quote)
{
    foreach ($quote['items'] as &$item) {
        if (empty($item['product_name']) || $item['product_name'] === 'Unknown Product') {
            // 調用產品API獲取產品名稱
            $productResponse = $this->goApiService->getProduct($item['product_id']);
            
            if ($productResponse && isset($productResponse['name'])) {
                $item['product_name'] = $productResponse['name'];
            }
        }
    }
    
    return $quote;
}
```

**實施效果**: 
- Unknown Product → 測試商品 A （✅ 修復成功）
- 保持系統架構穩定性
- 為後續 Go API 修復預留接口

### 3. Phase 3 分析：狀態寫入邏輯問題（根因定位）
**問題位置**: Go Backend API
**分析結果**: Laravel 端邏輯正確，問題在 Go API 端的狀態映射邏輯
**技術債務記錄**: 已確認為 Go API 端技術債務，需要專門的 Go 開發資源處理
