# NexusERP Dashboard - 公司資訊區域 UI/UX 優化

## 📋 優化概覽

本次優化重新設計了 NexusERP Dashboard 中的公司資訊顯示區域，提升了視覺效果和用戶體驗。

## 🎯 主要改進

### 1. **視覺層次優化**
- **結構化佈局**: 採用卡片式設計，明確的資訊分組
- **色彩指示器**: 使用彩色圓點區分不同類型的資訊
- **漸層背景**: subtle 漸層效果增強視覺深度
- **頂部裝飾條**: 紫色到藍色的漸層裝飾條增加品牌識別

### 2. **資訊組織改進**
- **雙欄佈局**: 業務資訊與系統狀態分欄顯示
- **標籤系統**: 業務類型和角色使用彩色標籤區分
- **狀態顯示**: 連線狀態、登入時間、權限等級一目了然
- **快速統計**: 底部統計區域顯示關鍵業務指標

### 3. **互動體驗提升**
- **懸浮效果**: 卡片懸浮時輕微上升並顯示陰影
- **動畫效果**: 漸進式載入動畫增強視覺體驗
- **響應式設計**: 完美適配不同螢幕尺寸
- **無障礙支援**: 支援減少動畫偏好設定

## 🎨 設計特點

### 顏色系統
- **主要色彩**: 延續 NexusERP 深色主題
- **強調色**: 紫色 (#8b5cf6) 作為主要強調色
- **狀態色**: 綠色(線上)、藍色(資訊)、橙色(警告)
- **漸層效果**: 使用 color-mix 創建自然過渡

### 佈局結構
```
公司資訊卡片
├── 頂部裝飾條 (漸層線條)
├── 公司選擇器區域
│   ├── 圖示 + "目前公司" 標題
│   └── 公司切換下拉選單
├── 資訊網格 (雙欄佈局)
│   ├── 業務資訊欄
│   │   ├── 業務類型 (紫色標籤)
│   │   └── 職務角色 (藍色標籤)
│   └── 系統狀態欄
│       ├── 連線狀態 (綠色)
│       ├── 上次登入 (青色)
│       └── 權限等級 (橙色)
└── 快速統計區域
    ├── 活躍訂單 (綠色)
    ├── 產品總數 (藍色)
    └── 客戶總數 (紫色)
```

## 🔧 技術實作

### 檔案結構
```
NexusERP/frontend/
├── resources/views/dashboard.blade.php (主要模板)
├── public/css/dashboard-company-info.css (專用樣式)
└── resources/views/components/reports-style.blade.php (系統樣式)
```

### CSS 特色
- **CSS 變數**: 完全使用 NexusERP 的 --nexus-* 變數系統
- **現代語法**: 使用 color-mix、grid、flexbox 等現代特性
- **動畫最佳化**: 使用 transform 和 opacity 避免重排
- **無障礙**: 支援 prefers-reduced-motion 媒體查詢

### JavaScript 整合
- **數據載入**: 整合到現有的 DashboardController
- **動態更新**: 支援即時數據更新
- **格式化**: 數字和貨幣格式化支援
