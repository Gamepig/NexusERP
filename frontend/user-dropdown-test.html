🔍技術修復詳情
根本原因：Alpine.js 事件處理競爭條件
原始問題：
  • 點擊按鈕觸發 toggleUserMenu() 開啟選單
  • 同時 @click.outside 檢測到外部點擊
  • 200ms 後選單自動關閉，使用者無法點擊登出
修復方案：
  • 使用 @click.stop 阻止事件冒泡
  • 實施 justOpened 保護機制
  • 延長關閉延遲至 300ms
  • 改進 timeout 管理邏輯
