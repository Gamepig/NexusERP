# Description: An urgent hotfix to resolve critical issues identified on 2025-07-22, including dashboard routing errors, broken third-party authentication, and missing UI features like theme switching.
# Details:
This is an urgent hotfix to be completed in 6 days, structured in four phases:

**Phase 1: Emergency Fixes (Days 1-2)**
*   **Dashboard Routing Error:** Isolate and fix the 'Undefined variable $slot' error in the core application layout to restore access to `inventory`, `reports`, `employees`, and `marketplace` pages.
*   **Google Authentication:** Debug and repair the existing Google registration flow. Check API keys, redirect URIs in Google Cloud Console, and frontend event listeners.

**Phase 2: Feature Completion (Days 2-3)**
*   **LINE Authentication:** Implement the new LINE login feature. This includes setting up a LINE developer app, integrating the `socialiteproviders/line` package, and building the frontend button and backend callback logic.
*   **Theme Switching:** Implement the dark/light mode toggle. Define color schemes via CSS variables and use JavaScript with `localStorage` to manage and persist the user's state.

**Phase 3: UI/UX Optimization (Day 4)**
*   **Button Contrast:** Correct the registration button's color contrast to meet WCAG AA accessibility standards.
*   **Design Style Unification:** Review all modified pages and components (auth, dashboards) to ensure they adhere to the `style/` directory guidelines.

**Phase 4: Enhancement & Integration Testing (Days 5-6)**
*   **AI-Guided Registration:** Enhance the AI registration assistant by improving prompts and integrating it more deeply with the knowledge base from Task 25 for better contextual help.
*   **Full System Test:** Execute the complete test strategy, including manual E2E flows, automated tests, and visual regression checks.

# Test Strategy:
**1. Routing Verification:** Manually navigate to `/inventory`, `/reports`, `/employees`, and `/marketplace`. Confirm that all pages load without the '$slot' error. Create automated feature tests to assert a 200 OK response and the presence of unique content on each page.
**2. Theme Switching Test:** Manually toggle the theme switch; verify UI elements update correctly. Confirm the theme choice persists after a page refresh. Write an E2E test (e.g., using Cypress) to automate toggling the theme and asserting the `<html>` element has the `.dark` class.
**3. Authentication E2E Tests:** a) Perform a complete registration and login cycle using a test Google account. b) Perform a complete registration and login cycle using a test LINE account. Verify that user profiles are created correctly in the database for both flows.
**4. Accessibility Audit:** Use browser developer tools (e.g., Lighthouse, Axe) to run an accessibility audit on the login/registration page, specifically verifying the button's color contrast score is compliant.
**5. AI Registration Flow:** Test the AI-guided registration by providing both valid and invalid inputs, and asking common questions to verify the quality and relevance of the AI's assistance.
**6. Visual Regression:** Perform a visual spot-check on all modified pages against the official UI mockups to ensure design consistency.
