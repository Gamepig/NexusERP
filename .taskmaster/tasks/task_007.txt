# Description: The AI-guided registration flow has been successfully implemented, allowing users to describe their business in natural language and receive structured ERP classification automatically, as per PRD 3.1.3.
# Details:
The `POST /api/auth/ai-register` endpoint is fully implemented. It accepts user input including `name`, `email`, `password`, and `business_description` (minimum 10 characters). This endpoint integrates with a mock AI service (for development) that performs keyword-based classification, identifying business types (Restaurant, Farm, Manufacturing, Services), industry (e.g., Food Service, Agriculture), scale (Small, Medium, Large), and complexity (Simple, Moderate, Complex), along with a confidence score. The classified data is automatically formatted into clean, structured YAML for frontend consumption. The AI classification data is persistently stored in the `ai_classification_yaml` JSONB field in the database, and the `registration_method` is tracked as 'ai-guided'. Upon successful registration, a `201 Created` status is returned, providing the complete user profile, the structured classification object, and its YAML representation, including a `requires_confirmation` flag based on the confidence level.

# Test Strategy:
The implementation was thoroughly tested by mocking the external LLM API. Tests covered data flow and YAML generation with various natural language inputs, ensuring robust parsing and classification. Specific successful test cases include: Restaurant classification (Food Service industry, Kitchen/Service/Management units), Farm classification (Agriculture industry, Production/Sales/Operations units), Manufacturing classification (Manufacturing industry, Production/Quality/Sales/Logistics units). Input validation for email format, password length, and business description length was verified, as was duplicate user detection. User login with AI-classified accounts was confirmed, and database storage was verified for proper JSONB structure of AI classification data.
