#### **2.2.2 優化 QuoteController 搜尋邏輯**
**執行時間**: 60 分鐘

**修改 QuoteController::index 方法**:
```php
public function index(Request $request)
{
    try {
        // 建立查詢參數，移除空值
        $queryParams = array_filter([
            'page' => $request->get('page', 1),
            'limit' => $request->get('limit', 20),
            'search' => $request->get('search'),
            'status' => $request->get('status'),
            'customer_id' => $request->get('customer_id'),
            'date_from' => $request->get('date_from'),
            'date_to' => $request->get('date_to'),
            'sort_by' => $request->get('sort_by', 'created_at'),
            'sort_direction' => $request->get('sort_direction', 'desc'),
        ], function($value) {
            return $value !== null && $value !== '';
        });

        $response = $this->callGoAPI('/api/quotes?' . http_build_query($queryParams));
        
        if ($response->successful()) {
            $quotes = $response->json();
            
            // 記錄搜尋參數供前端使用
            $searchParams = $request->only(['search', 'status', 'date_from', 'date_to']);
            
            return view('quotes.index', compact('quotes', 'searchParams'));
        }

        // API 調用失敗的降級處理
        Log::warning('Go API failed for quotes index', [
            'status' => $response->status(),
            'body' => $response->body(),
            'params' => $queryParams
        ]);

        return view('quotes.index', [
            'quotes' => ['quotes' => [], 'total' => 0, 'current_page' => 1, 'per_page' => 20],
            'searchParams' => $request->only(['search', 'status', 'date_from', 'date_to'])
        ])->with('warning', '無法載入報價單資料，請稍後再試');
        
    } catch (\Exception $e) {
        Log::error('Error fetching quotes: ' . $e->getMessage(), [
            'trace' => $e->getTraceAsString(),
            'params' => $request->all()
        ]);
        
        return view('quotes.index', [
            'quotes' => ['quotes' => [], 'total' => 0, 'current_page' => 1, 'per_page' => 20],
            'searchParams' => $request->only(['search', 'status', 'date_from', 'date_to'])
        ])->with('error', '載入報價單列表時發生錯誤');
    }
}
```

#### **2.2.3 添加即時搜尋功能 (可選)**
**執行時間**: 30 分鐘

**建立 JavaScript 即時搜尋**:
```javascript
// 在 index.blade.php 底部添加
<script>
document.addEventListener('DOMContentLoaded', function() {
    const searchForm = document.getElementById('searchForm');
    const searchInput = document.getElementById('search');
    const statusSelect = document.getElementById('status');
    
    let searchTimeout;
    
    // 即時搜尋 (防抖動)
    searchInput?.addEventListener('input', function(e) {
        clearTimeout(searchTimeout);
        searchTimeout = setTimeout(() => {
            if (e.target.value.length >= 3 || e.target.value.length === 0) {
                searchForm.submit();
            }
        }, 500);
    });
    
    // 狀態改變時立即搜尋
    statusSelect?.addEventListener('change', function() {
        searchForm.submit();
    });
    
    // 日期改變時立即搜尋
    document.getElementById('date_from')?.addEventListener('change', function() {
        searchForm.submit();
    });
    
    document.getElementById('date_to')?.addEventListener('change', function() {
        searchForm.submit();
    });
});
</script>
```
