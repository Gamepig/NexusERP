## 報價單轉為訂單（Convert）錯誤分析報告

### 現象
- 在報價列表中點擊「轉換為訂單」後，出現錯誤頁：
  - `Method Not Allowed` / `The GET method is not supported for route quotes/{id}/convert. Supported methods: POST.`

### 根因
1) 前端列表頁使用了 GET 連結觸發轉換

```601:609:frontend/resources/views/quotes/index.blade.php
@elseif($quote['status'] === 'approved')
    <!-- 轉換按鈕 -->
    <a href="{{ route('quotes.convert', $quote['id']) }}" 
       onclick="return confirm('確定要將此報價單轉換為銷售訂單嗎？')"
       class="...">
        轉換為訂單
    </a>
```

2) 路由定義要求 `POST`

```49:81:frontend/routes/modules/orders.php
Route::prefix('quotes')->name('quotes.')->group(function () {
  ...
  // Quote actions
  Route::post('/{id}/approve', ...)->name('approve');
  Route::post('/{id}/reject',  ...)->name('reject');
  Route::post('/{id}/convert', ...)->name('convert'); // ✅ 僅支援 POST
});
```

因此，點擊超連結（GET）呼叫 `quotes/{id}/convert` 會被框架拒絕，出現「Method Not Allowed」。

### 其他條件檢查（必要但非本次錯誤主因）
- 後端 Go 服務 `ConvertQuoteToSalesOrder` 僅允許狀態為 `approved` 的報價轉換，且會進一步檢查是否已過期等。

```513:596:backend/internal/services/quote_service.go
func (s *QuoteService) ConvertQuoteToSalesOrder(quoteID int64, req *models.ConvertQuoteRequest, userID int64) (...){
  quote, _ := s.GetQuoteByID(quoteID)
  if quote.Status != models.QuoteStatusApproved { return { Success:false, Message:"quote must be approved..." } }
  if quote.Status == models.QuoteStatusConverted { ... }
  if quote.ExpiryDate != nil && quote.ExpiryDate.Before(time.Now()) { ... }
  ...
}
```

### 修復方案
- 將列表頁的「轉換為訂單」改為 **POST 表單** 或 **按鈕 + JS 提交 POST**，包含 CSRF token：

```blade
<form method="POST" action="{{ route('quotes.convert', $quote['id']) }}" class="inline">
  @csrf
  <button type="submit" onclick="return confirm('確定要將此報價單轉換為銷售訂單嗎？')" class="...">
    轉換為訂單
  </button>
  </form>
```

或使用一個隱藏表單 + JS `document.getElementById('convert-{{ $id }}').submit()`。

### 驗證清單
- UI：點擊按鈕後不再看到 `Method Not Allowed`，而是正常導向訂單詳情頁或顯示 API 回覆訊息。
- API：
  - 狀態為 `approved` 的報價可成功轉換（HTTP 200/302）。
  - 非 `approved` 的報價，Go 回傳友善訊息（`quote must be approved before conversion`），前端顯示提示。

### 結論
- 本次錯誤的直接原因是 HTTP 方法不符：前端用 GET 觸發了需要 POST 的路由。改為 POST 表單提交即可解決；同時保留狀態檢查行為以匹配 Go 端限制。
