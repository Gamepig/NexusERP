## 🚨 關鍵問題清單與修復優先級

### 🔥 高優先級 (需立即修復)

#### 1. API 路由配置錯誤
**影響模組**: 庫存管理  
**問題**: 前端調用錯誤的 API 端點  
**錯誤**: `http://localhost:8080/api/...` 應為 `http://127.0.0.1:8000/api/...`  
**修復時間**: 30分鐘  
**修復方法**:
```javascript
// 檢查前端 API 配置
const API_BASE_URL = 'http://127.0.0.1:8000/api';
```

#### 2. 缺失的 API 路由
**影響模組**: 供應商管理、客戶管理  
**問題**: API 端點回傳 404  
**修復時間**: 2-4小時  
**修復方法**:
```php
// 在 routes/api.php 添加:
Route::get('/suppliers', [SupplierController::class, 'index']);
Route::get('/customers', [CustomerController::class, 'index']);
```

#### 3. 訂單管理模組完全缺失
**影響**: 核心業務功能無法使用  
**問題**: 路由、控制器、視圖都未實作  
**修復時間**: 1-2天  
**修復範圍**: 全套 CRUD 功能開發

### ⚠️ 中優先級 (1週內修復)

#### 4. 伺服器 500 錯誤
**影響模組**: 供應商管理、報表模組  
**問題**: 後端邏輯錯誤或資料庫問題  
**修復時間**: 4-8小時  

#### 5. 登出功能不可用
**問題**: UI 元素隱藏導致無法點擊  
**修復時間**: 1-2小時  

### 📝 低優先級 (可延後處理)

#### 6. 靜態資源缺失
**問題**: 預設圖片等資源 404  
**影響**: 視覺體驗，不影響功能  
**修復時間**: 1小時
