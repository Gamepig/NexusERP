# Identified MCP Servers

This document categorizes MCP servers based on their primary use case, identified from various sources including `awesome-mcp-servers` lists, directories like `mcpservers.org`, `glama.ai`, `cursor.directory`, and platform documentation.

*Note: Some servers might fit into multiple categories depending on the specific implementation and usage.*
