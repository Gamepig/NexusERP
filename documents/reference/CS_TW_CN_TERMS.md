# 台灣與中國計算機術語/用語對照表

兩岸不僅生活用語大不同，連專業領域之術語和名詞的翻譯也是有所差異。

其中電機（Electrical）、電子（Electronic）、通訊（Communication）、資訊（Information）、計算機工程（Computer engineering）和計算機科學（Computer science）等專業領域的差異最明顯。

不同作業系統、環境有不同的翻譯：
- win: Windows
- mac: macOS
