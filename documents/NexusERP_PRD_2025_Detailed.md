## 1. 專案概述

### 1.1 專案願景
NexusERP 是一套現代化、AI 驅動的企業資源規劃系統，專為中小企業及跨行業經營者設計。系統整合了傳統 ERP 功能與創新的 AI 技術，提供智能化的業務管理解決方案。

### 1.2 核心價值主張
- **智能化營運**：AI 驅動的預測、推薦、分析與自動化
- **跨行業整合**：支援單一企業多業務單位的整合管理
- **生態系連結**：Marketplace 平台促進供應商與買家連結
- **現代化體驗**：直觀的使用者介面與 AI 助手互動
- **彈性擴展**：模組化架構支援客製化需求

### 1.3 目標使用者
- **主要使用者**：中小型企業經營者，特別是跨行業經營者
- **次要使用者**：企業員工、部門主管、財務人員
- **生態系使用者**：Marketplace 供應商與買家

## 2. 系統架構與技術規格

### 2.1 技術堆疊
- **前端架構**：PHP/Laravel (Blade 模板) + Vite + Tailwind CSS
- **後端架構**：Go/Gin RESTful API
- **資料庫**：PostgreSQL (主要)、Redis (快取)
- **容器化**：Docker + Docker Compose
- **檔案儲存**：MinIO (S3 相容)
- **AI 整合**：外部 LLM API、MCP Server、RAG/CAG
- **監控**：Nginx、日誌系統

### 2.2 系統特性
- **模組化設計**：可獨立部署與擴展的功能模組
- **多租戶支援**：公司與業務單位層級的資料隔離
- **API 優先**：完整的 RESTful API 支援第三方整合
- **安全性**：JWT 認證、RBAC 授權、資料加密
- **可擴展性**：支援水平擴展與微服務架構

## 3. 核心功能模組詳細規格

### 3.1 用戶管理與認證系統

#### 3.1.1 功能概述
- 用戶註冊、登入、權限管理
- 支援 OAuth (Google, LINE) 第三方登入
- **AI 引導式註冊**：自然語言輸入，AI 自動分類行業與業務單位
- RBAC 權限控制系統

#### 3.1.2 技術細節
- **資料表**：users, roles, permissions, user_roles, role_permissions, user_oauth_accounts
- **API 端點**：
  - `POST /api/auth/register` - 註冊新用戶
  - `POST /api/auth/login` - 用戶登入
  - `POST /api/auth/ai-register` - AI 引導式註冊
  - `GET /api/users` - 用戶列表查詢
  - `PUT /api/users/{id}` - 更新用戶資料

#### 3.1.3 特殊功能
- **AI 註冊流程**：
  1. 用戶以自然語言描述經營內容
  2. AI NLP 分析自動分類行業、業務單位
  3. 系統以 YAML 格式回覆分類結果
  4. 用戶確認並補全資料
  5. 結構化資料存入資料庫

### 3.2 組織架構管理

#### 3.2.1 功能概述
- 公司主檔管理
- 多業務單位架構
- 員工資料與組織關係
- 跨業務單位權限控制

#### 3.2.2 技術細節
- **資料表**：companies, business_units, employees, user_business_units
- **API 端點**：
  - `POST /api/companies` - 建立公司
  - `POST /api/business-units` - 建立業務單位
  - `GET /api/business-units/{id}/users` - 查詢單位成員

#### 3.2.3 特殊功能
- **業務單位標籤**：每個業務單位可標記不同行業類型
- **資料隔離**：透過 `business_unit_id` 實現資料區隔
- **跨單位操作**：支援內部庫存轉移等跨單位業務

### 3.3 商品與庫存管理

#### 3.3.1 功能概述
- 商品主檔管理 (SKU, 分類, 規格)
- 多倉庫庫存管理
- 庫存異動追蹤
- 盤點作業流程

#### 3.3.2 技術細節

  - `POST /api/inventory-transactions` - 建立庫存異動
  - `POST /api/stocktaking-orders` - 建立盤點單

#### 3.3.3 特殊功能
- **多級分類**：支援階層式商品分類
- **多倉庫管理**：支援多倉庫、多儲位庫存
- **批號序號追蹤**：支援批號/序號管理
- **庫存預警**：基於安全庫存與消耗預測的自動預警

## 4. AI 功能整合規格

### 4.1 AI 助手系統

#### 4.1.1 功能概述
- 自然語言查詢與操作
- 智能業務建議
- 系統導航與教學
- 語音互動支援

#### 4.1.2 技術實現
- **核心技術**：大型語言模型 (LLM)、自然語言處理 (NLP)
- **整合方式**：外部 API 串接、MCP Server 整合
- **互動介面**：聊天視窗、語音輸入、懸浮按鈕

#### 4.1.3 功能範例
- "幫我找出上個月產品『智能感應器X1』在華東區的總銷售額"
- "草擬一份給供應商『德隆精密』的採購訂單"
- "偵測到關鍵原料價格上漲，建議評估採購計畫"

### 4.2 OCR 影像辨識

#### 4.2.1 功能概述
- 發票、進貨單、出貨單等文件識別
- 自動資料提取與驗證
- 多語言與手寫支援
- 與業務流程整合

#### 4.2.2 技術實現
- **OCR 服務**：外部 OCR API 整合
- **文件分類**：AI 自動分類文件類型
- **資料驗證**：提取資料的校驗機制

#### 4.2.3 處理流程
1. 上傳文件圖片或掃描件
2. AI 自動分類文件類型
3. OCR 提取文字資訊
4. NLP 解析結構化資料
5. 自動填入對應業務單據

### 4.3 智能分析與預測

#### 4.3.1 功能概述
- 銷售需求預測
- 庫存優化建議
- 供應商推薦
- 財務趨勢分析
- 異常檢測與預警

#### 4.3.2 技術實現
- **預測模型**：時間序列分析、機器學習模型
- **資料源**：內部業務資料 + 外部市場資料
- **分析引擎**：統計分析、商業智慧工具

#### 4.3.3 分析類型
- **描述性分析**：歷史資料統計與趨勢
- **預測性分析**：未來趨勢預測
- **指導性分析**：最佳決策建議

#### 4.4.1 功能概述

- 實現軟刪除機制

#### 7.1.2 主要資料表
- **用戶相關**：users, roles, permissions, user_roles, user_oauth_accounts
- **組織相關**：companies, business_units, employees
- **商品相關**：products, product_categories, units_of_measure
- **庫存相關**：warehouses, inventory_levels, inventory_transactions
